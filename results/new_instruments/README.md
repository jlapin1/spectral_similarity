# New-instrument I/L discrimination results

Figures and tables for extending the I/L sibling analysis to Orbitrap Astral and timsTOF,
generated by the scripts in `scripts/` and `make_predictions/`. See `CLAUDE.md` section 14
for the full method, environments, and data provenance. The underlying raw/converted
spectra live in the gitignored `temp_data/` and are not committed.

Fraction correct = observed spectrum more similar to the original than to the I/L swap
(0.5 = chance).

| File | Content |
|---|---|
| `figure7_multi_instrument.png` | Predicted MS2 similarity of I/L siblings, Orbitrap (UniSpec) vs Astral (Prosit HCD) vs timsTOF (AlphaPeptDeep). `multi_instrument_similarity.parquet` has the per-pair scores. |
| `figure_astral_ratio_correct.png` | Astral observed fragment-intensity discrimination, n=19,180 (best metric ~0.61). `astral_ratio_correct.csv`. |
| `figure_rt_{orbitrap,astral,timstof}.png`, `figure_rt_combined.png` | DeepLC RT-based discrimination per instrument (0.576-0.607, n=4000 each). `rt_discriminative.csv`. |
| `figure_timstof_mobility_il.png` | timsTOF observed ion-mobility separation, model-free (siblings indistinguishable from replicate noise, p=0.22). `timstof_mobility_il.csv`. |
| `sage_config.json` | Sage search configuration used for the timsTOF identifications. |

Modality summary (fraction correct, 95% CI; ion mobility is a separation test):

| modality | Orbitrap | Astral | timsTOF |
|---|---|---|---|
| fragment intensity | original analysis | ~0.61 | not produced (see CLAUDE.md section 14) |
| retention time | 0.603 [0.587-0.618] | 0.576 [0.560-0.591] | 0.607 [0.592-0.622] |
| ion mobility | n/a | n/a | no separation (p=0.22) |

The timsTOF fragment-intensity figure is not included: the timsTOF Pro `.d` could not be
read or converted in the working environment. See `CLAUDE.md` section 14 for the blocker
and how to complete it.
